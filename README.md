# AVS かんたん作成ツール（avs-maker）

**📖 使い方のページ：https://tatata17.github.io/avs-maker/** （ツールの「使い方」ボタンからも開けます）

VHS などのアナログ取り込み動画から AviSynth のスクリプト（.avs）を作り、そのまま ffmpeg（HEVC / NVENC）で mp4 にエンコードする Windows 用の GUI ツールです（`avs_maker.pyw`）。

- インターレース解除（KFMDeint）と、ブレンドされたアニメの 24p 化（QTGMC＋SRestore）を、区間ごとに使い分けられる
- 明るさ（Levels）・色相／彩度（Tweak）・色ノイズ除去（CCD）・リサイズ・色空間変換（BT.601→BT.709）
- 補正前／補正後を並べた比較画像をワンクリックでコピー（チャットに貼って相談するとき用）
- 動画ごとに別々の設定を持てる。設定はファイル名ごとに自動で記録され、次に同じ動画を追加すると戻る
- プリセット、設定のコピー／貼り付け
- 「更新を確認」ボタンで、このリポジトリの最新版に自動で入れ替え

## 1. 必要なもの

| もの | 用途 | 備考 |
|---|---|---|
| Python 3（Windows 版） | ツールを動かす | `.pyw` をダブルクリックで起動できるようにしておく |
| Pillow・numpy | プレビュー・比較画像・カット編集 | `pip install pillow numpy` |
| tkinterdnd2 | ドラッグ＆ドロップ | `pip install tkinterdnd2`（なくても「ファイルを追加…」で使える） |
| AviSynth Neo | 通常の処理（KFMDeint・CUDA） | パソコンにインストールしておく |
| AviSynth+ 3.7.5 の `avisynth.dll` | 24p 化（QTGMC＋SRestore） | インストールせず、24p 用 ffmpeg と同じフォルダに置く |
| ffmpeg（2つ） | プレビュー・エンコード | 通常用と 24p 用。avisynth に対応したビルド（gyan.dev の full build など） |
| NVIDIA の GPU とドライバ | HEVC（NVENC）エンコード | 新しい ffmpeg はドライバ 610 以降が必要 |

Pillow などが入っていなくてもツールは起動しますが、その機能だけ使えなくなります。

## 2. はじめての準備

### 2-1. ツールを置く

`avs_maker.pyw` を好きなフォルダに置きます。設定ファイルは、このファイルと同じフォルダに自動で作られます。
フォルダごとコピーすれば、別のパソコンにも設定ごと持っていけます。

### 2-2. ffmpeg を2つ用意する（大事）

ffmpeg は .avs を開くときに `avisynth.dll` を読み込みます。Windows は **ffmpeg.exe と同じフォルダの avisynth.dll を優先** し、なければパソコンにインストールされた AviSynth（Neo）を使います。
この仕組みを使って、2つの ffmpeg で使う AviSynth を分けます。

| 欄 | 例 | 同じフォルダの avisynth.dll | 使われる AviSynth |
|---|---|---|---|
| 通常用ffmpeg（Neo） | `C:\ffmpeg\ffmpegNEW.exe` | **置かない** | インストール済みの Neo |
| 24p用ffmpeg（3.7.5） | `C:\ffmpeg\NEW\ffmpeg.exe` | AviSynth+ 3.7.5 のもの | 3.7.5 |

- ffmpeg.exe の名前は変えても大丈夫です（例：`ffmpegNEW.exe`）。欄で選んだファイルがそのまま使われます。
- 通常用のフォルダに 3.7.5 の avisynth.dll があると、Neo 用の avs が 3.7.5 で開かれて「CUDA」のエラーになります（[困ったとき](#9-困ったとき)参照）。

### 2-3. 24p 化用のプラグインフォルダを作る

24p 化（AviSynth+ 3.7.5 側）は、Neo 用のプラグインと混ざらないように、**このフォルダだけ**を読み込みます（avs の先頭に `ClearAutoloadDirs()` と `AddAutoloadDir(...)` が入ります）。
初期値は `C:\avs_srestore` です。次のものを入れておきます。

- スクリプト（.avsi）：`QTGMC.avsi`、`Srestore.avsi`、`Zs_RF_Shared.avsi`
  （realfinder/AVS-Stuff の `avs 2.5 and up` / `avs 2.6 and up` フォルダにあります。`Zs_RF_Shared.avsi` は `AvsPlusVersionNumber` などを含むので必須）
- プラグイン（64bit の .dll）：`masktools2`、`RgTools`、`mvtools2`、`nnedi3`、`TIVTC`、`Average`、`grunt`
- CCD を 24p 化と一緒に使うとき：`VDubFilter.dll`（AviSynth+ 3.7.5 の filesonly 版に入っているもの）
- mp4 / mkv など AVI 以外を読むとき：LSMASHSource

`SMDegrain.avsi` は入れないでください（QTGMC の補助関数と名前がぶつかります）。

### 2-4. 初回起動

`avs_maker.pyw` をダブルクリックします。④ の ffmpeg の欄が正しいか確認し、違えば「選ぶ…」で選び直してください。変えた場所は自動で記録され、次からはその場所が使われます。

## 3. 基本の使い方

1. **動画を追加**：① に動画（またはフォルダ）をドラッグ＆ドロップするか、「ファイルを追加…」。
2. **動画を選ぶ**：一覧で選ぶと、右にその動画の1コマが表示され、② にその動画の設定が出ます。
3. **設定する**：② のチェックと数字を調整します。右のプレビューで補正後の見た目を確認できます（画像を押している間は補正前）。
4. **区間を決める（必要なら）**：右下の「カット編集」で残す区間を登録し、24p 化する区間に ☑ を付けます。
5. **実行**：右下の「avsを作成してエンコード」。avs だけ欲しいときは「avsだけ作成」。

出力先は ③ で選びます（動画と同じフォルダ／指定フォルダ）。同じ名前のファイルがあるときは上書き確認が出ます。

## 4. 画面の説明

どのボタン・チェック・入力欄も、**マウスを置いて少し待つと説明（ツールチップ）が出ます**。

### 画面の配置
- 左の列：① 動画ファイル・② 設定・③④ 保存先とエンコード・avs の中身。
- 右の列：画像プレビュー（いつも見える位置に固定）と、その下のタブ「チェックする場面」「カット編集（残す区間）」。
- 画面に収まらないときは、左の列と右の列が**別々に**スクロールします（マウスを置いた列だけが動きます）。
- ③④ は一度決めたらあまり触らないので、▶ ボタンでたためます。たたんでいる間も、横に「保存先・CQ・ffmpeg の指定状況」が出ます。ffmpeg の場所が決まっていないときは、自動で開きます。

### ① 動画ファイル
- 一覧には「ファイル名・処理・明るさ・色相／彩度・CCD」の要約が並びます。
- Ctrl／Shift で複数選択、Ctrl+A で全部選択。Delete キーで一覧から外せます（ファイル自体は消えません）。

### ② 設定（一覧で選んだ動画の設定）
上の「編集中：〇〇.avi」に、どの動画の設定を触っているかが出ます。

| 項目 | 内容 |
|---|---|
| 読み込み方法 | 自動なら avi は AviSource、それ以外は LWLibavVideoSource |
| インターレース解除（KFMDeint） | Neo（CUDA）で解除。24コマのアニメ部分は元のコマを組み直し、60i の部分は 59.94p のまま。普通のアニメや実写はこれ |
| フィールド順 | VHS の取り込みはほぼ TFF |
| アニメを24pにする（QTGMC＋SRestore） | 口や手が二重に見える（フィールドがブレンドされた）アニメ向け。区間を登録しているときは区間ごとの ☑ が優先 |
| 明るさ補正（Levels） | 入力 黒を上げると黒が締まる／入力 白を下げると明るくなる。出力は通常 16〜235 のまま |
| 色相・彩度の補正（Tweak） | 色相 －で緑寄り／＋で赤寄り。彩度 1.0 がそのまま |
| 色ノイズ除去（CCD） | VirtualDub の Color Camcorder Denoise（ツールに内蔵）。閾値 30 が目安 |
| リサイズ | 1440×1056 は 4:3 を正方形ピクセルにした大きさ（15:11） |
| 色空間変換 | BT.601 → BT.709。HD サイズで出すときはオン |

### ③ avs と mp4 の保存先
### ④ エンコード
- HEVC（NVENC）p7 / Main10 / BT.709、音声は FLAC（圧縮レベル 8）。
- 画質 CQ は小さいほど高画質（VHS 保存用なら 18〜20）。
- ffmpeg が `-tune uhq` に対応していないときは、確認のうえ `-tune hq` で続けます。

### 画像プレビュー
- 画像を押している間は「補正前」、離すと「補正後（Levels/Tweak の見本）」。
- 画像を押したあと ←→ で1コマ、Shift+←→ で1秒移動。
- **移動先**の欄にフレーム番号（例：`18743`）か時間（例：`10:25.4`、`1:02:03`）を入れて Enter で、その場面へ移動。
- **比較画像（コピー／保存…）**：左に補正前、右に補正後を並べ、下にファイル名・フレーム番号・設定を書き込んだ画像を作ります。「コピー」してチャットに Ctrl+V で貼れます。
- プレビューの補正後は Levels / Tweak の見本です。インターレース解除・CCD・24p 化の効果は出ません（CCD がオンのときは注意書きが出ます）。

### チェックする場面
設定を変えるたびに同じ場面を見直すための機能です。
- 見比べたい場面（一番明るい場面・暗い場面・顔のアップなど）で「この場面を覚える」。1本の動画に8つまで。
- リストをクリックすると、その場面へすぐ移動します。
- 「まとめてコピー」で、覚えた場面すべての比較画像（左＝補正前／右＝補正後）を縦に並べた1枚がコピーされます（「まとめて保存…」で画像として保存）。いちばん下に設定の要約が入ります。
- 覚えた場面は動画ごとに記録され、次に同じ動画を追加したときも残っています（同じ名前でも中身が違うファイルでは消えます）。

### 補正アシスタント（上級者向け）
② の右上の「補正アシスタント…」で、別ウインドウが開きます。覚えた場面（チェックする場面）を大きく表示して、補正を詰めるための道具です。ウインドウの大きさは自由に変えられます。

- **表示**：補正後／補正前／左右で比べる（下のつまみで境目を動かせる）。
- **白飛び・黒潰れを色で表示**：模様が消えている所を、赤の斜線（白飛び）と青の斜線（黒潰れ）で塗ります。潰れているのが夜空や背景だけなのか、顔の影まで潰れているのかが一目で分かります。黄色の点線の外（VHS の端の縁や下のノイズ）は判定しません。
- **覚えた場面と判定**：場面ごとに白飛び・黒潰れの割合と、補正後の一番暗い所（最暗部。大きいと黒が浮いている）を表示。赤字は多めの場面です。
- **黒は演出／白は演出**：その欄を押して ☑ にすると、その場面のその判定を、おすすめ値の計算から外します。夜の場面の真っ黒な空、クレジットの文字の黒い影、光っている物など、潰れていて正しい場面に使います。
- **おすすめの明るさ**：どの場面も潰れにくい「入力 黒」「入力 白」を出します。どの場面で値が決まったかも表示されるので、その場面が演出なら ☑ を入れます。「この値を使う」でメイン画面に入ります。
- **肌の色**：画像の肌の部分をクリックすると「肌の見本」に登録されます（場面をまたいで何点でも。右クリックで消す）。自然な肌色の範囲（24〜42°）から外れているときだけ、範囲に入る一番小さな色相を「色相を −10 にする」のように提案します。
- 演出のチェックと肌の見本は、動画ごとに記録されます。

## 5. 動画ごとの設定・プリセット

### 動画ごとの設定
- ② を変えると、**一覧で選んでいる動画にだけ**反映されます。
- 複数選んで変えると、**変えた項目だけ**が選んだ全部に反映されます。値が動画ごとに違う項目は「※選んだ動画で値が違う項目：…」と赤字で出ます。
- 新しく追加した動画は、そのとき選んでいた動画の設定を引き継ぎます（同じシリーズを続けて追加すると同じ設定になる）。
- ffmpeg の場所・保存先・画質（CQ）・24p 用プラグインのフォルダは、全部の動画で共通です。

### コピー／貼り付け
- 「設定をコピー」→ ほかの動画を選んで「選んだ動画に貼り付け」。
- 「全部の動画に適用」で一覧の全部に。どちらもカット区間はそのままです。

### プリセット
- 「今の設定を保存…」で名前を付けて保存（同じ名前なら上書き）。
- プリセットを選んで「選んだ動画に適用」。

### 自動の記録
ツールと同じフォルダの `avs_maker_動画ごとの設定とプリセット.json` に、動画ごとの設定とプリセットをまとめて保存します。

- 同じ**ファイル名**の動画を次に追加すると、設定が戻ります（「前回の設定を復元しました」と表示）。
- カット区間は、ファイルの大きさが同じとき（同じ中身のとき）だけ戻します。同じ名前で取り込み直したファイルに古い区間が付くのを防ぐためです。
- 別々のフォルダに同じ名前の動画があるときは、最後に使ったほうの設定が出ます。
- 記録は最大 2000 本。超えると古いものから消えます。
- 設定は変えてから約1秒後に自動保存されます。

## 6. カット編集と 24p 化

### 区間の登録
1. プレビューで位置を合わせ、「ここを開始点に」「ここを終了点に」。
2. 「この区間を残す ＋」。開始点だけなら最後まで、終了点だけなら先頭からそこまで。
3. 区間名をダブルクリックすると、その区間の開始位置へ移動します。

区間のフレーム番号は、取り込んだままの動画（29.97fps）の番号です。

### 区間ごとの 24p 化
区間リストの左端の □ を押すと、その区間だけ 24p 化（QTGMC＋SRestore）が ☑ になります。

- 24p 化する区間が1つでもある動画は、**全部の区間を QTGMC で 59.94p にしてから**、☑ の区間だけ SRestore で 24p にして、59.94p に戻して（同じコマを複製して）1本につなぎます。この動画は 24p 用 ffmpeg（3.7.5）でエンコードされます。
- 下から上に流れる文字（警告文・スクロールするクレジット）や、ビデオ編集で付けたパン・ディゾルブは 60i で作られていることが多いので、**24p 化しない（59.94p のまま）**区間にします。24p 化するとカクカクになります。

### KFMDeint と 24p 化の使い分け

| 素材 | おすすめ |
|---|---|
| 普通のアニメ（テレシネがきれい） | KFMDeint（24p 化なし）。24コマ部分と 60i 部分を自動で見分ける |
| 実写・ホームビデオ | KFMDeint |
| 口や手、鳥などが二重に見えるアニメ（ブレンド） | 本編を 24p 化。警告文などは 59.94p のまま |

見分け方：動きのある場面で二重像が出るか見る。KFMDeint で二重像が出て、24p 化で消えるなら 24p 化。

## 7. 補正の決め方（おすすめの手順）

1. **場面を選ぶ**：一番明るい場面（白い紙・雲・窓・クレジットの文字）、一番暗い場面（夜・黒い服）、人物の顔のアップを探す。
2. **明るさ（Levels）**：
   - 一番明るい場面で、白が上限に張り付かない（白飛びしない）ところまで「入力 白」を下げる。
   - 暗い場面で、影の中のディテールが潰れないところまで「入力 黒」を上げる（上げすぎると黒潰れ）。
   - クレジットの白い文字の中が上限に届くのは問題なし（文字の中に模様はないため）。
（補正アシスタントを使うと、2 と 3 のおすすめ値を自動で出せます。）
3. **色（Tweak）**：顔のアップで肌の色を見る。肌がピンク〜赤っぽいテープだけ色相を －5〜－10。もともと自然なら色補正はしない（回しすぎると赤い物がオレンジに、肌が黄色っぽくなる）。白い雲などが水色っぽい「色かぶり」は色相では直らない。
4. **比較画像で確認**：1で探した場面を「この場面を覚える」で登録しておき、設定を変えるたびに「まとめてコピー」。全部の場面の補正前／補正後が1枚にそろうので、チャットに貼って相談すると早い。
5. **同じシリーズ・同じ取り込み方なら**、1本目で決めた設定をプリセットにして使い回す。巻ごとに肌の色だけ確認する。

### 設定例
| 素材 | 設定 |
|---|---|
| 安定装置で明るさ −16 にして取り込んだテープ | `Levels(24, 1.0, 210, 16, 235)`、色補正は肌を見て 0 か −5 |
| 肌がピンク寄りのアニメ | `Tweak(hue=-10)`、必要なら彩度 1.1〜1.15 |
| 実写の舞台（スポットライトあり） | 白飛びしやすいので「入力 白」は控えめ（220 前後）か補正なし |

## 8. 更新のしかた

ツール左下の「**更新を確認**」を押します（横に今の版番号が表示されています）。

1. このリポジトリの `version.json` と比べ、同じなら「最新版です」。
2. 新しい版があれば、変更内容を表示します。「はい」でダウンロード。
3. ダウンロードしたファイルが壊れていないか・版番号が合っているかを確かめてから、入れ替えます。
4. 前の版は `avs_maker_old.pyw` として残ります。新しい版で不具合が出たら、それを起動すれば戻せます。
5. 再起動すると新しい版になります。

設定（`avs_maker_settings.json`）と、動画ごとの設定・プリセット（`avs_maker_動画ごとの設定とプリセット.json`）は消えません。

GitHub への反映直後は、数分ほど古い版が案内されることがあります。そのときは少し待ってから押し直してください。

## 9. 困ったとき

| 症状・メッセージ | 原因と対処 |
|---|---|
| `This Avisynth does not support memory type 2 (CUDA)` | Neo 用の avs を 3.7.5 で開いている。通常用 ffmpeg のフォルダに 3.7.5 の `avisynth.dll` を置かない |
| 「このffmpegは -tune uhq に対応していません」 | 古い ffmpeg。「はい」で `-tune hq` で続けられる（差はごくわずか）。新しい ffmpeg を選べば出なくなる |
| `Driver does not support the required nvenc API version` | NVIDIA ドライバが古い。610 以降（Studio ドライバ推奨）に更新 |
| `I don't know what "AvsPlusVersionNumber" means` など、関数がないというエラー（24p 化） | 24p 用プラグインフォルダに `Zs_RF_Shared.avsi` などが足りない（[2-3](#2-3-24p-化用のプラグインフォルダを作る)） |
| `LoadVirtualDubPlugin` がない（24p 化＋CCD） | 24p 用プラグインフォルダに `VDubFilter.dll` を入れる |
| `RequestLinear: internal error (frame not cached)` | プレビューで大きくシークしたときに出る。エンコードは先頭から順番なので通常は出ない。区間の少し前から送って確認する |
| プレビューが真っ黒・赤字で「先頭のコマを表示しています」 | 動画の長さを読めていない。「この場面を取り直す」で読み直す。ffprobe（ffmpeg と同じフォルダ）を確認 |
| エンコードが途中で止まったまま進まない | ドライバ更新直後の初回などに起きることがある。中止してやり直す。続くなら `-tune uhq` の古い ffmpeg を疑う |
| 24p 化した区間でスクロールやパンがカクカク | その場面が 60i で作られている。その区間を 24p 化しない区間に分ける |
| 24p 化しても二重像が少し残る | 元のテープで前後のコマが全部混ざっている場面。ソフトではほぼ限界 |
| 日本語のパスで avs が開けない | avs は日本語環境の文字コード（cp932）で保存します。扱えない文字があるときは UTF-8 で保存し、作成時にお知らせが出ます |

ffmpeg のエラーで失敗したときは、mp4 と同じ場所に `〇〇_ffmpeg.log`（実行したコマンドと ffmpeg の出力）が保存されます。
