AVS かんたん作成ツール 使い方

VHS などの取り込み動画から AviSynth のスクリプト（.avs）を作り、そのまま ffmpeg（HEVC / NVENC）で mp4 にエンコードする Windows 用のツール avs_maker.pyw の説明です。

KFMDeint / QTGMC＋SRestore Levels・Tweak・CCD 比較画像をワンクリックでコピー チェックする場面をまとめて比較 補正アシスタント 動画ごとの設定・プリセット ボタンひとつで更新
⬇ avs_maker.pyw をダウンロード 最新版を確認中…　2回目からは、ツールの「更新を確認」で入れ替えられます。
ヒントツールのボタン・チェック・入力欄は、マウスを置いて少し待つと説明（ツールチップ）が出ます。

AviSynth+ 3.7.5 の avisynth.dll24p 化（QTGMC＋SRestore）AviSynth+ v3.7.5 の filesonly 版から取り出す。インストールせず、24p 用 ffmpeg と同じフォルダに置く
ffmpeg（2つ）プレビュー・エンコードgyan.dev の full 版（avisynth に対応）。zip の bin の ffmpeg.exe・ffprobe.exe を使う。通常用と 24p 用の2組

02はじめての準備

2-1. ツールを置く

avs_maker.pyw を好きなフォルダに置きます。設定ファイルはこのファイルと同じフォルダに自動で作られるので、フォルダごとコピーすれば、別のパソコンにも設定ごと持っていけます。

2-2. ffmpeg を2つ用意する

ffmpeg は .avs を開くときに avisynth.dll を読み込みます。Windows は ffmpeg.exe と同じフォルダの avisynth.dll を優先し、なければパソコンにインストールされた AviSynth（Neo）を使います。この仕組みで、2つの ffmpeg が使う AviSynth を分けます。

欄例同じフォルダの avisynth.dll使われる AviSynth
通常用ffmpeg（Neo）C:\ffmpeg\neo\ffmpeg.exe置かないインストール済みの Neo
24p用ffmpeg（3.7.5）C:\ffmpeg\avs375\ffmpeg.exeAviSynth+ 3.7.5 のもの3.7.5
  • フォルダ名は例です。neo は通常用（AviSynth Neo）、avs375 は 24p 用（AviSynth+ 3.7.5）の意味で付けています。2つが別のフォルダになっていれば、名前は自由です。
  • ffmpeg.exe の名前は変えても大丈夫です（例：ffmpeg_neo.exe）。欄で選んだファイルがそのまま使われます。
注意通常用 ffmpeg のフォルダに 3.7.5 の avisynth.dll があると、Neo 用の avs が 3.7.5 で開かれて「CUDA」のエラーになります。

2-3. 24p 化用のプラグインフォルダを作る

24p 化（AviSynth+ 3.7.5 側）は、Neo 用のプラグインと混ざらないように、このフォルダだけを読み込みます。初期値は C:\avs_srestore です。次のものを入れておきます。

スクリプト（.avsi）

QTGMC.avsi・Srestore.avsi・Zs_RF_Shared.avsi
realfinder/AVS-Stuff にあります。Zs_RF_Shared は必須

プラグイン（64bit .dll）

masktools2・RgTools・mvtools2・nnedi3・TIVTC・Average・grunt

CCD を使うとき

VDubFilter.dll（AviSynth+ 3.7.5 の filesonly 版に入っているもの）

AVI 以外を読むとき

LSMASHSource（mp4・mkv など）。L-SMASH-Works

入れないものSMDegrain.avsi は入れないでください。QTGMC の補助関数と名前がぶつかってエラーになります。

2-4. 初回起動

avs_maker.pyw をダブルクリックします。④ の ffmpeg の欄が正しいか確認し、違えば「選ぶ…」で選び直します。変えた場所は自動で記録され、次からはその場所が使われます。

03基本の使い方

  1. 動画を追加① に動画（またはフォルダ）をドラッグ＆ドロップするか、「ファイルを追加…」。
  2. 動画を選ぶ一覧で選ぶと、右にその動画の1コマが表示され、② にその動画の設定が出ます。
  3. 設定する② のチェックと数字を調整します。右のプレビューで補正後の見た目を確認できます（画像を押している間は補正前）。
  4. 区間を決める（必要なら）右下の「カット編集」で残す区間を登録し、24p 化する区間に ☑ を付けます。
  5. 実行右下の「avsを作成してエンコード」。avs だけ欲しいときは「avsだけ作成」。

出力先は ③ で選びます（動画と同じフォルダ／指定フォルダ）。同じ名前のファイルがあるときは上書き確認が出ます。

  • HEVC（NVENC）p7 / Main10 / BT.709、音声は FLAC（圧縮レベル 8）。
  • 画質 CQ は小さいほど高画質（VHS の保存用なら 18〜20）。
  • ffmpeg が -tune uhq に対応していないときは、確認のうえ -tune hq で続けます。

画像プレビュー

  • 画像を押している間は「補正前」、離すと「補正後（Levels/Tweak の見本）」。
  • 画像を押したあと ←→ で1コマ、Shift+←→ で1秒移動。
  • 移動先の欄にフレーム番号（例：18743）か時間（例：10:25.4、1:02:03）を入れて Enter で、その場面へ移動。
  • プレビューの大きさは、ウインドウの大きさに合わせて自動で変わります。
  • 今の場面の比較画像（「チェックする場面」タブの「コピー／保存…」）：左に補正前、右に補正後を並べ、下にファイル名・フレーム番号・設定を書き込んだ画像を作ります。「コピー」してチャットに Ctrl+V で貼れます。

チェックする場面

設定を変えるたびに、同じ場面を見直すための機能です。

  1. 場面を覚える見比べたい場面（一番明るい場面・暗い場面・顔のアップなど）で「この場面を覚える」。1本の動画に8つまで。
  2. すぐ移動リストをクリックすると、その場面へすぐ移動します。
  3. まとめて比較「まとめてコピー」で、覚えた場面すべての比較画像（左＝補正前／右＝補正後）を縦に並べた1枚がコピーされます。いちばん下に設定の要約が入ります。「まとめて保存…」で画像として保存もできます。

覚えた場面は動画ごとに記録され、次に同じ動画を追加したときも残っています（同じ名前でも中身が違うファイルでは消えます）。

補正アシスタント（上級者向け）

② の右上の「補正アシスタント…」で別ウインドウが開きます。覚えた場面を大きく表示して、補正を詰めるための道具です。ウインドウの大きさは自由に変えられます。

白飛び・黒潰れを色で表示

模様が消えている所を、赤の斜線（白飛び）と青の斜線（黒潰れ）で塗ります。潰れているのが背景だけか、顔の影までかが一目で分かります。黄色の点線の外（VHS の端の縁など）は判定しません。

場面ごとの判定

白飛び・黒潰れの割合と、補正後の一番暗い所（最暗部。大きいと黒が浮いている）。赤字は多めの場面です。

黒は演出／白は演出

☑ にすると、その場面のその判定をおすすめ値の計算から外します。夜空の黒、クレジットの文字の影、光る物など、潰れていて正しい場面に。

おすすめの明るさ

どの場面も潰れにくい「入力 黒」「入力 白」。どの場面で値が決まったかも表示します。「この値を使う」でメイン画面に入ります。

肌の色

画像の肌をクリックして見本に登録（右クリックで消す）。自然な範囲（24〜42°）から外れているときだけ、範囲に入る一番小さな色相を提案します。

表示は「補正後」「補正前」「左右で比べる」（下のつまみで境目を動かせる）から選べます。演出のチェックと肌の見本は動画ごとに記録されます。

プレビューで分かるもの補正後の見本に反映されるのは Levels と Tweak だけです。インターレース解除・CCD・24p 化の効果は出ません（CCD がオンのときは注意書きが出ます）。

05動画ごとの設定・プリセット

動画ごとの設定

  • ② を変えると、一覧で選んでいる動画にだけ反映されます。
  • 複数選んで変えると、変えた項目だけが選んだ全部に反映されます。値が動画ごとに違う項目は「※選んだ動画で値が違う項目：…」と赤字で出ます。
  • 新しく追加した動画は、そのとき選んでいた動画の設定を引き継ぎます。
  • ffmpeg の場所・保存先・画質（CQ）・24p 用プラグインのフォルダは、全部の動画で共通です。

コピー／貼り付け

「設定をコピー」→ ほかの動画を選んで「選んだ動画に貼り付け」。カット区間はそのまま。

全部の動画に適用

確認のあと、一覧の全部に今の設定を適用します。

プリセット

「今の設定を保存…」で名前を付けて保存。選んで「選んだ動画に適用」。

自動の記録

ツールと同じフォルダの avs_maker_動画ごとの設定とプリセット.json に、動画ごとの設定とプリセットをまとめて保存します。

  • 同じファイル名の動画を次に追加すると、設定が戻ります（「前回の設定を復元しました」と表示）。
  • カット区間は、ファイルの大きさが同じとき（同じ中身のとき）だけ戻します。同じ名前で取り込み直したファイルに古い区間が付くのを防ぐためです。
  • 別々のフォルダに同じ名前の動画があるときは、最後に使ったほうの設定が出ます。
  • 記録は最大 2000 本。設定は変えてから約1秒後に自動保存されます。

06カット編集と 24p 化

区間の登録

  1. プレビューで位置を合わせ、「ここを開始点に」「ここを終了点に」。
  2. 「この区間を残す ＋」。開始点だけなら最後まで、終了点だけなら先頭からそこまで。
  3. 区間名をダブルクリックすると、その区間の開始位置へ移動します。

区間のフレーム番号は、取り込んだままの動画（29.97fps）の番号です。

リストの上の「区間の表示」で、時間・フレーム番号・両方を切り替えられます（初期は両方。選んだものは次の起動でも同じ）。フレーム番号だけにすると、長さも「コマ数」で出ます。

区間ごとの 24p 化

区間リストの左端の □ を押すと、その区間だけ 24p 化（QTGMC＋SRestore）が ☑ になります。

  • 24p 化する区間が1つでもある動画は、全部の区間を QTGMC で 59.94p にしてから、☑ の区間だけ SRestore で 24p にし、59.94p に戻して（同じコマを複製して）1本につなぎます。24p 用 ffmpeg（3.7.5）でエンコードされます。
59.94p のまま残すもの下から上に流れる文字（警告文・スクロールするクレジット）や、ビデオ編集で付けたパン・ディゾルブは 60i で作られていることが多いので、24p 化しない区間にします。24p 化するとカクカクになります。

KFMDeint と 24p 化の使い分け

素材おすすめ
普通のアニメ（テレシネがきれい）KFMDeint（24p 化なし）。24コマ部分と 60i 部分を自動で見分ける
実写・ホームビデオKFMDeint
口や手、鳥などが二重に見えるアニメ本編を 24p 化。警告文などは 59.94p のまま

見分け方：動きのある場面で二重像が出るか見ます。KFMDeint で二重像が出て、24p 化で消えるなら 24p 化です。

07補正の決め方（おすすめの手順）

  1. 場面を選ぶ一番明るい場面（白い紙・雲・窓・クレジットの文字）、一番暗い場面（夜・黒い服）、人物の顔のアップを探します。
  2. 明るさ（Levels）一番明るい場面で白が上限に張り付かない（白飛びしない）ところまで「入力 白」を下げ、暗い場面で影が潰れないところまで「入力 黒」を上げます。クレジットの白い文字の中が上限に届くのは問題ありません。
  3. 色（Tweak）顔のアップで肌の色を見ます。肌がピンク〜赤っぽいテープだけ色相を −5〜−10。もともと自然なら色補正はしません（回しすぎると赤い物がオレンジに、肌が黄色っぽくなります）。白い雲などの「色かぶり」は色相では直りません。
  4. 補正アシスタントで詰める（任意）覚えた場面の白飛び・黒潰れの判定と、明るさ・肌の色のおすすめ値を出せます。暗い／明るいのが演出の場面は ☑ で外します。
  5. 比較画像で確認1で探した場面を「この場面を覚える」で登録しておき、設定を変えるたびに「まとめてコピー」。全部の場面の補正前／補正後が1枚にそろうので、チャットに貼って相談すると早いです。
  6. 使い回す同じシリーズ・同じ取り込み方なら、1本目の設定をプリセットにして使い回し、巻ごとに肌の色だけ確認します。

設定例

素材設定
安定装置で明るさ −16 にして取り込んだテープLevels(24, 1.0, 210, 16, 235)、色補正は肌を見て 0 か −5
肌がピンク寄りのアニメTweak(hue=-10)、必要なら彩度 1.1〜1.15
実写の舞台（スポットライトあり）白飛びしやすいので「入力 白」は控えめ（220 前後）か補正なし

08更新のしかた

ツール左下の「更新を確認」を押します（横に今の版番号が表示されています）。

  1. 確認GitHub の version.json と比べ、同じなら「最新版です」。
  2. 変更内容を表示新しい版があれば、何が変わったかを表示します。「はい」でダウンロード。
  3. 安全に入れ替えダウンロードしたファイルが壊れていないか・版番号が合っているかを確かめてから入れ替えます。
  4. 前の版は残る前の版は avs_maker_old.pyw として残ります。新しい版で不具合が出たら、それを起動すれば戻せます。
  5. 再起動再起動すると新しい版になります。
設定は消えませんavs_maker_settings.json と avs_maker_動画ごとの設定とプリセット.json はそのまま残ります。GitHub への反映直後は、数分ほど古い版が案内されることがあります。
