# 使い方ページ(docs/index.html)のルール

m2ts-encoder / avs-maker / syncdub の3つの使い方ページは、同じデザイン・同じ書き方でそろえています。
どれか1つを更新するときは、他の2つと食い違わないようにしてください。

- デザイン(`<style>` の「共通デザイン」部分)と共通スクリプトは、3ページで同一の内容。変えるときは3つとも変える。
- 章の名前は共通: 「必要なもの(と〜)」「更新のしかた」「困ったとき」「ファイルの場所」「更新履歴」。章番号は2桁(01, 02…)で、目次は見出しと同じ番号・名前にする。
- 注意書きは `.note`(ヒント・補足)と `.warn`(注意)。見出しは `<b class="lb">` 。表は `.table-wrap` で包む。
- 更新履歴は日付ごとにまとめ、最新の日だけ開いて、古い日は折りたたむ。ユーザーの役に立つ項目だけ載せる。
- ffmpeg は「full」版。入れかた(PATH の説明を含む)は3ページで同じ文章にし、ツールごとの違いだけ書き分ける。
- 公開ページ・README・更新履歴に、録画した番組名や放送局・サービス名を書かない。例は架空のものを使う。
- 文末は「です・ます」。括弧は半角 ( )、「ドラッグ&ドロップ」の表記をそろえる。
